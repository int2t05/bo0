科研软件与可复核工作流

按“收集资料 → 组织笔记 → 编写和运行代码 → 管理版本与环境 → 生成论文/报告”查找官方操作资料。适合需要具体软件帮助时按步骤取用，不是软件选型排名。

核验说明： 本分册收录 123 个唯一网址，均于 2026-11-16 从软件官方文档中打开并核对标题与操作用途；未逐一安装、操作或测试软件。软件版本和界面会变，具体操作以当前版本文档为准。遇到重定向循环或未返回可读内容的候选页不纳入；跳转后仍能读取的官方页面保留。

文献管理：Zotero

  • 入门：文档总览 · 安装 · 快速开始。
  • 收集与迁移：添加文献条目 · 添加文件 · 从 PDF 获取元数据 · 从其他文献管理器迁移 · 数据目录与备份说明。
  • 整理与阅读：分类与标签 · 检索 · 排序 · 重复条目合并 · PDF 阅读器与批注 · 笔记 · 相关条目 · 条目报告。
  • 引用与协作：创建参考文献表 · 文字处理器集成 · Word 插件用法 · Google Docs 集成 · 引用样式 · 同步 · 群组库。

笔记与个人知识库：Obsidian

  • 建库与基础写作：官方帮助首页 · 安装 · 创建第一条笔记 · 链接笔记 · 导入笔记 · Obsidian Markdown 扩展 · 附件管理。官方说明笔记以本地纯文本 Markdown 文件存储，便于用普通文件工具访问。
  • 结构与导航：Properties 元数据 · Bases 表格视图 · 核心插件目录 · Canvas 画布 · Graph View 图谱 · 模板 · 每日笔记 · 反向链接 · 搜索。
  • 捕获、扩展与恢复：Web Clipper · 剪藏模板 · 社区插件 · 文件恢复 · 备份笔记库 · 跨设备同步 · 设置 Sync · Sync 功能说明 · 更新软件 · 设置。官方帮助提醒：同步不等于备份；社区插件会运行第三方代码，启用前需审查。

编程环境与依赖管理

  • Python：官方教程（面向已有编程基础、刚学习 Python 的读者） · 虚拟环境 venv · Windows 专题。
  • Python 打包：项目打包教程 · pip 与 venv 安装包 · pyproject.toml 规范 · src 布局与平铺布局。
  • Conda：文档首页 · 管理环境 · 创建环境命令 · 导出环境 · 管理 Channels · 管理包。
  • VS Code 的 Python 工作流：Python 功能总览 · Python 环境 · 运行 Python · 调试 · Notebook 与交互窗口。

代码版本与协作：Git

  • Pro Git 第二版是系统教程；核心章节：版本控制概念 · 安装 Git · 暂存与提交 · 查看历史 · 撤销与修正 · 远程仓库。
  • 分支与版本：分支和合并 · 分支管理 · 分支工作流 · 远程分支 · 暂存未提交工作 · 选择提交版本 · Git 命令参考。Pro Git 第二版出版于 2014 年，适合学习基础概念；命令细节和新功能以当前 Git 手册为准。

交互式计算：Jupyter

  • Project Jupyter 文档 · Jupyter Notebook 文档 · Notebook 用户文档 · Notebook 运行代码示例。
  • JupyterLab：文档首页 · 开始使用 · Notebook 操作 · 终端 · 文件管理。
  • 输出与比较：nbconvert 文档 · 命令行转换 · nbdime Notebook 差异比较与合并。

可执行论文与报告：Quarto

  • 入门与项目：开始使用 Quarto · 项目结构 · 代码执行管理 · 项目配置组合。
  • 写作与计算：Markdown 基础 · 运行 Python · 执行选项 · 插图 · 表格 · 交叉引用 · PDF 输出。
  • 论文与发布：Quarto 学术手稿 · 在 VS Code 中编写手稿 · 发布到 GitHub Pages。引用页面在网页抓取中只返回重定向，本轮未列作已核验链接。

LaTeX 写作：Overleaf

  • 入门：LaTeX 教程目录 · 30 分钟入门 · 项目结构 · 选择编译器与 TeX Live。
  • 公式与版面：数学表达式 · 用 amsmath 排列公式 · 插入图片 · 图表浮动位置 · 表格 · 页码设置 · 多语言排版 · 代码块。
  • 引用与排错：BibTeX 参考文献 · biblatex 参考文献 · 常见错误 · 颜色设置。部分 Learn 页面会重定向到新的 Overleaf Docs；访问时以跳转后的页面为准。

建议路径

先用 Zotero 捕获并管理文献，再在笔记中记录问题、证据和出处；用 Python/Conda 建立隔离环境，以 Git 保存代码变化；Notebook 用于交互式探索，Quarto 或 LaTeX 用于整理可执行报告或论文。需要同步时另做备份；插件和第三方扩展先看来源、权限与维护状态。
