2026-11 至 2027-06 阶段路线图

最后复核：2026-11-11
本页是训练阶段和优先级的权威入口。每周任务从当前阶段目标中选取，并按实际作品调整；它不是预先排好的任务日历。

总体目标

截至 2027 年 6 月，优先建立科研素养与习惯，掌握基础科研方法，为“面向炼化生产调度的工业垂类大模型”课题打牢 EC × LLM × 炼化调度的交叉基础。目标是能用作品说明自己如何提出问题、找证据、读论文、设计小实验、解释结论和复盘。

课题方向是长期主线，当前仍处于基础学习阶段；不要求形成正式博士研究问题、判断研究空白、深挖炼化工艺或完成工业调度模型。通用调度玩具问题用于建立建模语言，不代表项目模型。时间窗口只是规划参考，学习证据和现实投入决定节奏。

优先级与并行关系

层级 内容 安排原则
主线 P0 科研素养、研究习惯与基础方法 全程贯穿；周任务优先服务这条主线
并列基础 P1-A 优化与通用调度建模 从决策变量、目标、约束和评价开始，用公开或玩具问题练习；逐步联系炼化调度，不建立真实工艺模型
并列基础 P1-B EC/群智算法 先理解领域问题、方法谱系、适用条件和局限，再学习代表算法；当前不按算法名词逐个铺开
并列基础 P1-C LLM 使用与 API 接口 与 EC 和调度建模并列，按实际进度安排小任务，记录调用并核验输出
可选背景 P2 双网建模 正式项目含义未确认；只在有帮助时了解公开概念，不作必修前置

并列的是学习支线，不是要求同周并行开工。为降低新手认知负荷，每周通常只有一个主任务；每日目标数量按实际可用学习日确定，常见为五项，特殊周可少于五项或调整日期。所有目标共同完成该周任务。

阶段一：科研基础与课题交叉领域基础

参考窗口： 2026-11 至 2026-12，按实际进度调整。

  • 建立阅读、记录来源、保存尝试和复盘的习惯。
  • 理解科研问题、方法、实验、证据和结论之间的关系。
  • 掌握通用优化问题与简单调度模型的表达方式；能从变量、目标、约束和评价理解问题，而非先背算法名称。
  • 建立 EC/群智算法的领域地图，逐步了解代表方法的研究动机、机制与局限；不把自然启发故事当作算法解释。
  • 学会 LLM 基本使用与 API 调用概念，能核验输出并保护密钥和数据。
  • 将炼化调度作为长期应用领域逐步学习；当前只用公开资料和通用例子，不扩展到真实工艺。
  • 双网保持可选背景状态，正式含义待确认。

阶段出口（能力证据，不是任务清单）

  • 能将通用优化或调度小问题写成变量、目标和约束，并解释候选方案如何评价。
  • 能通过来源说明 EC/群智算法所处的学科背景与主要问题；后续再逐步掌握代表算法的机制和限制。
  • 能说明一次 LLM API 请求的基本流程；若环境受限，能用 mock 记录请求流程。
  • 能区分方法陈述与来源证据，知道单次结果不能证明普遍有效。

阶段二：科研阅读与文献证据

参考窗口： 2027-01 至 2027-02，按阶段一作品和阅读负担调整。

练习检索、筛选和来源定位；选适当综述与代表性论文阅读；理解综述的分类方式；精读一篇论文并标注问题、机制、对照、证据和结论边界。不把综述的 future work 自动当成已证实的研究空白。届时可从小导师列出的分布式/多智能体 EC、昂贵/数据驱动优化、LLM × EC 方向中选一篇作为训练样本；这些是方向入口，不预先指定为博士子课题。

阶段出口： 能从原文定位主张与证据，区分作者主张/实验结果/个人推断，并说明仍不理解之处。

阶段三：科研问题与实验方法

参考窗口： 2027-03 至 2027-04，按编程和数学起点调整。

在公开、低成本的玩具问题上练习“观察—问题—假设—实验—解释”；学习变量、指标、控制条件、对照、预算、重复运行、随机性和复现记录；计划先于结果，保留失败与负结果。

阶段出口： 能写可检验假设、替代解释和削弱假设的结果；按计划保存原始数据；谨慎说明结论范围和混杂因素。

阶段四：整合、复盘与方向认知

参考窗口： 2027-05 至 2027-06，按前期作品决定范围。

用作品检查基础能力是否形成连贯流程；将 EC、LLM/API、炼化调度及可能的双网背景整理成高层概念图，标出已理解、粗略了解、待了解和暂不展开；依据证据总结优势、缺口和下一阶段计划，不补写未经验证的技术路线。

阶段出口： 每项能力判断链接到作品；能复述一个训练问题从来源/观察到方法、实验和结论的过程；提出可执行的下一阶段方向，不强求博士选题或创新点。

周任务如何产生

  1. 判断当前阶段目标与近期能力缺口。
  2. 检查已有作品、前置知识、提示依赖和现实可投入时间。
  3. 选择一项服务科研主线的周目标；优化/调度建模、EC、LLM/API 按现实进度安排，不要求一周并行学完。
  4. 按实际可用学习日拆分每日小目标，通常为五项；特殊周可调整数量。每项约不超过 2 小时，所有目标共同完成周交付。
  5. 收到作品后再决定补交、重做、迁移练习或推进下一阶段。

阶段目标稳定，任务可调整、重排、缩小或跳过。当前属于阶段一。TASK-001 按一套教程从决策与建模推进到搜索、应用和证据判断；任务入口见训练任务看板。
