科研诚信与 AI 协作

本页是 AI 输出核验纪律的唯一权威：全站涉及 AI 协作与科研诚信的操作约定以此为准，其他文件只放指针。所在机构正式规定优先于本页。

AI 可以帮助什么

  • 解释术语、提出检索词和可能的对照方法。
  • 把用户提供的原文整理成可检查的结构。
  • 辅助写代码、检查公式、生成实验脚手架。
  • 对已有论点提出反例、替代解释和遗漏变量。
  • 根据证据整理初稿，但由研究者逐条核实并负责。

不得把生成结果当证据

  • LLM 输出不是论文来源。凡涉及事实、论文细节、政策或接口行为，回到原文/官方页面核查。
  • DOI、作者、卷期、页码、模型名和 API 参数逐条验证。
  • 如果模型无法支持引用，删除或标成未核实，不猜。
  • 不让 AI 替学生形成研究结论，也不让自动生成摘要冒充已读原文。

保留人的判断和来源

对关键结论保留输入、原始来源、命令、模型版本、参数、环境和人工修改。学校、期刊和项目的正式规范仍需遵守；训练档案记录 AI 在具体作品中的用途。

数据与秘密

未经许可，不向外部模型上传工业工艺参数、企业数据、未公开论文草稿、个人信息、账号凭证或 API 密钥。学习 API 时使用公开或合成的无敏感测试文本，并设置调用预算。

诚实报告

报告阴性结果和失败运行；不删除对主张不利的实验；不挑选性汇报。图表应能回到原始数据，手工修改要记录。

来源
